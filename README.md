One haiku about debugging — three lines, 5-7-5 syllables, at most 200 characters — written to `/output/entry.txt` by `main.py`.

> cursor blinks at three
> the log insists nothing changed
> it was my typo

Entry for the [Seventeen Syllables of Debugging](https://make.fun/c/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) bounty on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

It writes the haiku to `/output/entry.txt` and self-checks the gate: UTF-8 text, 1–200 characters, exactly 3 lines, 5-7-5 syllables.
